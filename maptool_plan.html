얼음판 맵툴

Unity 에디터 안의 맵툴 창에서 얼음판 모양을 칠해 JSON 파일로 저장하면, 게임이 그 파일을 읽어 얼음 타일맵으로 만든다. 지금은 가로×세로 직사각형만 만들 수 있지만, 맵툴로 구멍·섬·금 간 칸이 있는 판을 미리 디자인할 수 있게 된다.

전체 흐름

맵툴 창LionIceRun > 맵툴
→
맵 JSONStreamingAssets/Maps/*.json
→
IceGrid게임 시작 때 읽어 블럭 생성

JSON은 사람이 읽고 git으로 비교하기 쉽게 한 줄에 한 행씩 글자로 저장한다. 맵 파일이 없거나 고르지 않으면 지금처럼 가로×세로 꽉 찬 판을 만든다.

칸 종류

글자칸게임에서단계
.빈칸 (바다)처음부터 블럭이 없음. 서면 떨어짐. 얼음 복구 아이템으로도 안 생김1단계
I얼음지금 블럭과 같음 (3번 밟으면 흔들림 → 깨짐)1단계
C금 간 얼음"살짝 금" 단계로 시작 → 2번 만에 흔들림. 천천히 부서짐도 바로 시작3단계
T두꺼운 얼음멀쩡함 앞에 단계가 2개 더 있음 (5번 밟아야 흔들림). 하얀 서리 무늬로 구분3단계

깨지지 않는 칸은 넣지 않는다. 블럭이 모두 결국 깨져야 "맵 위에 한 명만 남는" 순간이 반드시 오기 때문이다.

표시 (칸 위에 얹는 것)

  • 플레이어 시작 칸 1개 (필수). 지금의 StartCell(가운데 칸)을 대신한다. 첫 이동 전까지 깨지지 않는 규칙은 그대로.
  • 봇 시작 칸 0개 이상. 봇 수보다 적으면 남은 봇은 지금처럼 무작위 칸에 선다.

맵툴 창 미리보기

실제 창의 구성을 흉내 낸 예시다. 칸을 클릭하거나 드래그해서 칠하면 오른쪽에 저장될 JSON과 검사 결과가 바로 바뀐다.

    JSON 형식
    
    
    
      
    키내용
    
      
        
    version형식 번호 (지금 1). 나중에 형식이 바뀌어도 예전 파일을 읽을 수 있게
    
        
    name맵 이름 (화면·목록 표시용). 파일 이름은 영어로 따로 (holey_island.json)
    
        
    width / depth가로(x) / 세로(z) 칸 수. 1~16
    
        
    rows한 행에 한 글자열. rows[0]이 맵툴 화면의 맨 위 행 (= z가 가장 큰 행), 글자 순서는 x 0부터
    
        
    playerStart{"x":3,"y":3} (y가 z 칸 번호. Unity Vector2Int 그대로)
    
        
    botStarts같은 형식의 목록
    
          
    
    
    
    Unity 기본 JsonUtility로 읽고 쓴다 (추가 패키지 없음). 칸 크기·간격·얼음 깨짐 수치는 맵에 넣지 않고 지금처럼 IceGrid Inspector 값을 쓴다.
    
  
    

  
    
    
    코드 변경
    
    
    
      
    파일할 일
    
      
        
    MapData.cs (새)JSON과 같은 모양의 클래스. 읽기·쓰기, 칸 종류 확인, 기본 맵(꽉 찬 직사각형) 만들기
    
        
    IceGrid.csInspector에 Map File(맵 목록 드롭다운). 비어 있으면 지금처럼. 빈칸은 블럭을 안 만듦. GetBlock을 2차원 배열로 바꿈 (지금은 꽉 찬 판을 가정해 x * depth + z 순번으로 찾음 → 빈칸이 있으면 어긋남). StartCell은 맵의 플레이어 시작 칸
    
        
    IceBlock.csInit에 시작 단계(금 간 얼음)와 추가 단계 수(두꺼운 얼음). 두꺼운 얼음의 서리 표시
    
        
    BotManager.cs봇 첫 위치에 맵의 봇 시작 칸 먼저 사용
    
        
    Editor/MapEditorWindow.cs (새)맵툴 창 (메뉴 LionIceRun > 맵툴)
    
        
    그대로 동작카메라·바다 크기(가로×세로 기준), 다시 들어오기·아이템·시련(멀쩡한 블럭 목록 기준), 봇 길 찾기(GetBlock이 빈칸에 null), 남은 얼음 수 표시
    
          
    
    
  
    

  
    
    
    맵툴 창 기능
    
    
      
      
    • 파일: 새로 만들기, 불러오기(맵 목록), 저장, 다른 이름으로 저장, 삭제. 저장 안 한 변경이 있으면 제목에 * 표시
      • 
      
    • 크기: 가로·세로 1~16. 바꿔도 이미 칠한 칸은 가운데 기준으로 유지
      • 
      
    • 칠하기: 브러시 고르고 왼쪽 클릭·드래그, 오른쪽 클릭은 빈칸으로. 채우기(이어진 같은 칸 한 번에), 모두 얼음 / 모두 비우기
      • 
      
    • 대칭 그리기: 좌우 / 상하 / 4방향. 공정한 맵을 빨리 만들기 위해
      • 
      
    • 되돌리기: Ctrl+Z / Ctrl+Y (Unity Undo 사용)
      • 
      
    • 검사: 저장 전에 자동으로. 문제가 있어도 저장은 되지만 빨간 줄로 알림 (아래 표)
      • 
      
    • 씬에 미리보기: 지금 씬의 IceGrid에 이 맵을 지정하고 블럭을 미리 만들어 보여 줌
      • 
      
    • 이 맵으로 플레이: 지정한 뒤 바로 Play 모드 시작
      • 
    
    
    
    
      
    검사등급
    
      
        
    플레이어 시작 칸이 없거나 빈칸 위에 있음오류
    
        
    얼음 칸이 (봇 수 + 1) × 3칸보다 적음오류
    
        
    점프(빈칸 1개)로도 갈 수 없는 떨어진 섬이 있음경고
    
        
    봇 시작 칸이 겹치거나 플레이어 시작 칸 바로 옆경고
    
        
    봇 시작 칸이 봇 수보다 적음 (남은 봇은 무작위)알림
