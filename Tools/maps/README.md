# 기믹 맵 레벨 디자인

## 추가 파티 스테이지 (2026-10-07)

기존 얼음 생존/5판 규칙에 새 스테이지 6개를 추가했다. `Tools/maps/add_party_stages.py`로 이 6개만 다시 생성할 수 있다. 기존 맵·사용자 BigMap을 덮어쓰거나 선택 목록에서 숨기지 않는다. 현재 선택 가능한 맵은 BigMap 포함 총 19개다.

| 파일 | 이름 | 레벨 디자인 |
|---|---|---|
| seesaw_summit | 시소 눈마루 | 반대 타이밍으로 기울어지는 긴 시소 두 개, 넓은 외곽 우회로 |
| blink_boulevard | 반짝 다리 거리 | 1초 전 얼음/등 색 경고 후 사라지는 두 다리, 8초 주기·4초 시차 |
| bounce_carnival | 통통 점프 축제 | 네 발사대와 중앙 회전 막대, 점프로 막대를 피하고 착지 위치 선택 |
| hammer_junction | 해머 교차로 | 네 방향 왕복 해머, 서로 다른 주기/위상의 통로 |
| trick_garden | 장난감 균형 정원 | 작은 시소·반짝 다리·중앙 해머, 좁은 연결 길과 피난 섬 |
| sky_picnic | 구름 위 피크닉 | 왕복 셔틀·기울어지는 섬·점프 발사대의 환승 경로 |

새 종류: `seesaw`(period/phase/tiltAngle/angle), `blink`(period/phase/activeDuration), `launcher`(liftSpeed 5~9), `pendulum`(period/phase/tiltAngle/angle). 시소는 하중 대신 경기 시각으로 기울어져 솔로/온라인에서 같은 움직임을 갖는다. 반짝 발판은 파괴 상태와 별개로 렌더/콜라이더만 켜고 끄며, 잠시 꺼졌다 켜져도 깨진 얼음을 자동 복구하지 않는다. 발사대는 조작 가능한 수직 점프이며 방패를 소비하거나 넘어뜨리지 않는다. 해머는 방패·타격 재사용 대기·넘어짐/밀침 규칙을 따른다.

모든 새 맵은 네 출발 칸과 기믹 밖의 이동 안전 시작 칸 두 개를 가진다. 룰렛 카드·맵툴 기믹 목록·호스트 판정/복제·봇 발 디딜 곳 갱신에 포함된다. 안전 효과는 시소/반짝 다리 같은 기믹 발판을 제외한 정적인 연결 경로에서 움직인다.

빌드는 요청받을 때만 진행한다. 이번 작업은 Assets와 맵 JSON 변경이며 EXE/ZIP을 만들지 않는다.

선택 목록: 기존 기본 맵 4개 + 테마 맵 8개. 기존 작은 빙판·얼음 고리·모래시계 빙하·네 섬 교차로를 남긴다. 나머지 기존 맵 11개는 `archived: true`로 룰렛/온라인 후보에서 제외하며 파일과 씬 참조는 보존한다. 맵툴에서 보관 체크를 해제하면 다시 나온다.

| 맵 | 중심 기믹 | 이동 선택 |
|---|---|---|
| 왕복 항구 | 가로 왕복 빙판 2개 | 외곽 다리와 왕복 지름길 |
| 시계태엽 빙원 | 큰 회전 빙판 | 회전 모서리에서 접근·탈출 |
| 피스톤 협곡 | 시차가 있는 피스톤 2개 | 십자 통로와 대피 구역 |
| 사탕 회전목마 | 반대로 회전하는 작은 빙판 2개 | 회전 타이밍에 맞춰 발판 이동 |
| 택배 빙하 | 반대 방향 컨베이어 2줄 + 피스톤 | 가로 연결로로 컨베이어 전환 |
| 풍차 우물 | 중앙 회전 막대 | 좁은 다리에서 점프 회피 |
| 밀물 셔틀 | 서로 다른 주기의 세로 왕복 빙판 | 이동 발판 또는 바깥 다리 |
| 극지 공장 | 회전 + 왕복 + 피스톤 | 서로 다른 장치 사이 경로 선택 |

네 출발 구역은 외곽 길로 연결한다. 기본 게임은 마지막까지 남는 서바이벌이다. 움직이는 빙판도 밟으면 깨지며 아래에 영구 바닥은 없다. 115초에 전체 붕괴 안내, 120초부터 10초마다 일반 얼음을 한 단계씩 진행한다. `S`는 이동 안전 효과의 시작 칸이다. 기존 테마 맵 12개에는 시작 칸이 2개씩 있고, 새 사용자 맵 BigMap처럼 S가 없는 맵은 원래 설정을 유지한다. 초록색과 노란 + 표시가 있는 현재 안전 칸은 얼음 파괴를 받지 않지만 충돌·바람·밀치기·기절은 받는다.

경기 시작 뒤에는 입력 없이도 밟은 일반 얼음이 금 간다. 서 있기 진행 4초·자연 금 진행 12초·흔들림 대기 2초·밟기 중복 방지 0.5초로 조정했다. 준비/카운트다운 중에는 보호한다. 안전 효과의 시작 칸을 더 칠하려면 맵툴의 `이동 안전지대 시작` 브러시(단축키 7)를 사용한다.

안전 효과는 각 칸에서 10초 유지한 후 인접한 다음 얼음 칸으로 이동한다. 8~10초에는 안전 색이 일반 얼음 색으로 보간되고 + 표시가 작아져 사라진다. 다음 위치에서는 처음 2초 동안 안전 색과 + 표시가 나타난다. 이전 칸은 일반 얼음으로 돌아가며, 다음 칸이 파괴된 상태라면 복구한다. 발판이 플레이어를 물리적으로 운반하는 방식은 아니다.

경로는 맵의 정적인 얼음 모양과 S 시작점에서 결정적으로 생성한다. 네 방향 인접 칸을 따라 연결 구역을 나누고, 구역별 깊이 우선 순회·귀환을 반복하므로 빈칸을 뛰어넘거나 안전 경로가 서로 겹치지 않는다. 이동/회전/컨베이어 발판은 별도 기믹이므로 이 경로에서 제외한다. 온라인은 호스트가 보낸 경기 시간으로 동일 경로와 보호 판정을 확정하고, 클라이언트는 다음 스냅샷까지 색만 보간한다. 통신 프로토콜은 3이므로 이전 EXE와 함께 플레이할 수 없다.

회전 막대/피스톤은 기본 수평 타격 10m/s·위로 3.2m/s·넘어짐 1.05초다. 회전 막대는 접촉 반경의 회전 속도도 반영한다. 회전/이동 발판 옆면 타격은 받지만 윗면 승객은 운반한다. 타격 뒤에는 전용 감속으로 미끄러지며, 막대와 발판은 1.2초 재타격 대기를 둔다. `hitSpeed/liftSpeed/knockDownSeconds`로 맵별 세기를 조절할 수 있다. 찬바람 힘은 22로 강화했다.

## 편집

`LionIceRun > 맵툴`에서 파일을 불러오면 새 기믹 목록·테마·안내·보관 옵션을 수정할 수 있다. `이 맵으로 플레이`로 검사한다. Scene에서 IceGrid를 선택하면 장치 크기·이동 시작/끝 경로를 Gizmos로 보여준다. 원본 Main 씬과 사용자 HUD 배치는 변경하지 않는다.

JSON `gimmicks`: `kind`는 `move`, `rotate`, `piston`, `sweeper`, `conveyor`. `x/z`는 중심 칸 좌표, `width/depth`는 크기(칸), `dx/dz`는 이동 거리(칸), `period`는 초, `phase`는 피스톤 시차(초), `speed`는 회전도/초 또는 컨베이어 m/초, `angle`은 장치 방향이다. move는 원점에서 목적지까지 코사인 왕복한다. 피스톤은 0.9초 예고 후 전진·유지·후퇴한다. 미리보기의 청록색은 이동/회전, 노란색은 컨베이어, 분홍색은 밀침 장치다.

`add_gimmick_maps.ps1`은 맵 원본을 다시 생성하는 유지보수 스크립트이며, 실행하면 해당 8개 맵의 수동 편집 내용을 덮어쓴다. 일반 플레이에는 실행할 필요가 없다.

온라인 장치는 서버 시각을 공유하고 충돌·방패·얼음 붕괴 판정은 호스트만 수행한다. 기믹 설정도 맵 해시에 포함되어 서로 다른 레벨 데이터는 공통 후보로 선택되지 않는다. 이동 발판의 실제 얼음 위치를 AI 길찾기 그리드에 투영한다. 움직이는 길을 기다리는 장기 경로 예측은 아직 없으며 AI는 현재 위치에서 안전한 길을 재탐색한다.
