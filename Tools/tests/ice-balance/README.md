# 얼음·안전지대·타격 밸런스 검사

빌드 없이 Unity 6000.6.3f1 에디터의 실제 Main 씬에서 검사한다. 복사 프로젝트의 Assets/Scripts에 `IceBalanceRunner.cs`, Assets/Scripts/Editor에 `IceBalanceEntry.cs`를 넣는다.

실행: `-batchmode -nographics -projectPath <복사본> -executeMethod IceBalanceEntry.Run -logFile <로그>`. 러너가 종료하므로 `-quit`는 넣지 않는다. PlayerPrefs는 CodexTests/IceBalance로 격리한다.

밸런스 검사 63개와 기존 온라인 규칙 36개·5판 규칙 23개 통과.

- 준비 중 일반 얼음 보호, 시작 후 이동 입력 없이 금 진행.
- 기존 Main 씬에서 새 시간 적용. 가만히 선 일반 얼음은 6초에도 유지되고 약 10.04초에 파괴.
- 활성 12개 맵 각각 안전 칸 2개, 일반 시작 위치 유지.
- 안전 칸의 밟기·강제 금 진행·강제 파괴 면역, 원격 파괴 상태에도 보호.
- 60초 전체 붕괴 제거, 120초부터 일반 얼음만 진행.
- 회전 막대 타격의 넘어짐/기존 밀침 취소/2m 이상 실제 이동·연속 타격 보호·방패 1회 방어.
- 회전 발판 옆면의 실제 물리 접촉에 따른 넘어짐, 기존 씬 바람 힘 22.

회전 발판 접촉 검사는 여러 물리 단계를 기다려 충돌 이벤트까지 관찰한다. 처음 두 물리 단계만 기다린 검사는 접촉 처리 완료 전을 검사했으므로 5단계로 수정했다. 검사 결과 파일에는 접촉 위치/법선 기록이 있다.

그래픽 없이 실행하므로 실제 화면의 넘어짐 연출·조작감과 새 기믹의 실제 Relay 2인 플레이는 별도 확인이 필요하다. 원본 Main 씬/HUD를 직접 수정하지 않는다.
