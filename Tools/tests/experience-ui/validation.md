## 최신 변경: 밝은 게임 UI·타이틀 설정·경사 물리

네이비/민트 카드 틀, 영문 홍보 문구, 그라데이션을 제거했다. 전체 모드 선택/로비/결과/설정/채팅/감정표현은 밝은 얼음색·흰색 배경과 노랑/주황/파랑 버튼, 짧은 한국어 메뉴를 사용한다. 캐릭터 주변의 큰 카드 프레임을 없애고 버튼에 낮은 그림자를 넣었다. 설정은 타이틀 시작 버튼 아래에만 배치한다. 맵 선택은 저장된 값이 없으면 **5초**이며 1~15초 직접 입력과 저장한 값은 유지한다.

`PlayerController`가 기울어진 `MapMovingSurface`에서 경사면의 낮은 방향을 구해 지속적인 미끄러짐 속도를 더하고, 오르막 입력 성분을 경사에 따라 줄인다. 경사 접촉 속도는 면에 접하도록 계산하며 올라가는 접촉을 점프로 오인하지 않는다. 점프/다이브는 기존 공중 경로를 사용한다. 평지·Ready·원격 표시 캐릭터는 보호하며 호스트/솔로/AI/로컬 클라이언트 예측은 같은 구현을 사용한다.

최신 `results.txt`: **59개 통과**, 기존 온라인 42개·5판 23개도 통과. `web-ime.test.cjs` 10개 통과. 실제 Rigidbody/BoxCollider 18도 발판에서 0.65초 입력 비교: 평지 오르기 약 2.85m, 경사 정지 시 내리막 약 1.82m, 경사 오르막은 약 0.40m 뒤로 밀림, 내리막 입력 약 4.67m. 경사 방향을 뒤집고 로컬 예측을 켜면 반대쪽으로 약 1.82m 이동했으며 다섯 경우 모두 접지를 유지했다. 수치 기록 `slope-motion.txt`. 강한 경사는 점프를 섞어 올라가야 하는 설계다. 실제 시소가 시간에 따라 움직일 때의 난이도 체감과 서로 다른 PC의 온라인 물리 회귀는 별도 플레이 확인이 필요하다.

화면은 `title.png`, `modes.png`, `settings.png`, `emote-wheel.png`, `chat.png`. 테스트 렌더이며 원본 Unity 창/현재 itch.io 버전을 캡처한 것은 아니다. 원본 씬 YAML 직접 편집·빌드·업로드는 하지 않았다. 아래는 앞선 구현과 검사 이력이다.

사용자 요청은 새 UI 디자인, 조작 키 변경과 Shift 기본 다이브, 솔로 닉네임, 동물 이름 익명 표시, T 감정표현, 한글 입력, 지연 부담을 줄인 채팅이다. 원본 씬 YAML을 편집하거나 게임을 빌드하지 않고 복사본 Unity 프로젝트에서 검사했다. 기존 배포 ZIP/itch.io에는 아직 이번 변경이 없다.

## 적용

- `IceExperienceUI`가 메인 씬 로드 시 자동 연결된다. 이미지 파일 대신 `IceUIShape` 메시로 둥근 버튼/카드를 그린다. 기존 캐릭터 모델과 선택 기능을 유지한다. 에디터 미리보기 메뉴는 **LionIceRun > 새 UI 디자인 적용·미리보기**다.
- 설정에 이동/점프/다이브/밀치기/감정표현/채팅 키 변경과 저장, 중복 방지, 기본값 복원, 익명/채팅 표시를 넣었다. Gamepad 기존 바인딩은 유지한다.
- 솔로 이름표·점수 및 온라인 명단·점수·새 채팅에 공개 이름을 사용한다. 익명 모드는 선택 동물 이름을 공개하고 개인 닉네임은 로컬 설정에 보존한다.
- 감정표현은 T 누름→드래그→놓기, 가운데/ESC는 취소다. 캐릭터 위에 메시 아이콘을 표시하고 온라인에서는 호스트를 통해 전달한다.
- 채팅은 온라인 방의 Enter 입력, 120자, 최근 6개, 긴 내용 스크롤, 표시 끄기를 지원한다. 별도 이름 메시지로 이벤트가 있을 때만 전송하며 이동 패킷을 변경하지 않는다. 호스트가 발신자·시퀀스·길이·채팅 1초/감정표현 1.2초 간격을 검증한다. WebSocket 자체의 지연 특성은 남으므로 모든 실제 환경에서 입력 지연이 없다고 보장하지 않는다.
- 설정/휠/채팅/문자 입력 중 경기 입력을 차단한다. 추가 검사에서 발견한 채팅 도크 경계 초과와 설정 중 솔로 결과 R 재시작을 수정했다. 밝은 얼음 위 안내에는 남색 배경을 추가했다.
- Windows는 TMP/Input System IME, Web은 브라우저 DOM 입력을 사용한다. Web 조합 중 Enter가 전송되지 않으며 blur/submit의 마지막 글자와 입력 종료 후 키보드 포커스를 보존한다. 전체 화면에 DOM 입력도 포함한다.

## 후속 변경: 빈 닉네임·맵 선택 속도

닉네임 입력/설정 저장에는 `OnlineRules.OptionalNickname`을 사용해 빈값을 보존한다. 실제 공개 이름은 `GamePreferences.PublicName`이 선택 스킨의 사자/북극곰/호랑이로 채운다. 직접 입력한 닉네임은 기존처럼 정리·16자 제한을 적용하고, 네트워크 이름 검증의 기존 비어 있지 않은 기본값은 유지한다. 입력창에는 “비워두면 동물 이름으로 시작해요”를 안내한다.

설정의 **맵 선택 (초)**는 1~15초를 직접 입력하며 기본 2초, 소수도 허용한다. 기존 빠르게/보통/여유롭게 설정은 2/4/7초로 읽어 보존한다. 회전/감속/선택 표시를 전체 시간의 30/55/15%로 나누고 이동 속도를 맞춰 카드 중앙에 정지한다. 카드 정렬 때문에 지정 시간보다 감속이 길어지지 않는다. 온라인에는 0.5초 동기화 여유가 추가되며 맵 로딩과 경기 3초 카운트다운은 별도다. 선택 도중 설정을 바꿔도 이번 판 시간은 유지하고 다음 판에 적용한다.

최종 `results.txt`는 UI/입력 49개 실패 0이며 `EXPERIENCE_EDITOR_SETUP_PASSED`는 편집 메뉴 적용·씬 저장·IceExperienceUI 참조·Play 설정창 연결을 확인한다. `relay-custom-time/`에서 방장 3.5초·클라이언트 10초를 입력해 양쪽 선택 합계 **3.500초**와 경기 시작을 확인했다. 원본 Unity 창은 computer-use 접근 승인 시간 만료로 최종 화면 확인을 못 했다. 원본 파일은 수정했고, Unity의 Assets > Refresh 이후 자동 디자인 적용 또는 LionIceRun > 새 UI 디자인 적용·미리보기 메뉴를 사용할 수 있다. 씬 YAML 직접 편집은 하지 않았다.

아래는 숫자 직접 입력으로 변경하기 전 속도 프리셋의 회귀 기록이다.

`relay-fast-retry/host-roll.txt`·`client-roll.txt`에서 5판 모두 회전/감속/선택 표시 합계 1.970초가 일치했다(온라인 동기화 여유 별도). 양쪽 최종 합산 17/14/11/8, 채팅·감정표현·익명 변경 및 편도 180ms/10% 손실 로컬 반응도 통과했다. 첫 실행은 테스트 인증 프로필을 구분하지 않아 “이미 로비 참가자”로 거절되었고, 서로 다른 테스트 프로필로 수정 후 통과했다. 제품 코드를 이 테스트 오류 때문에 변경하지 않았다.

추가로 `relay-speed-mismatch/`에서 테스트 제품 이름까지 분리해 설정 저장소를 나눴다. 방장은 빠르게(localSpeed=0), 클라이언트는 여유롭게(localSpeed=2) 상태에서 양쪽 선택 합계 1.970초 일치와 경기 시작을 확인했다. 같은 PC에서 같은 제품 이름을 쓰면 PlayerPrefs가 공유되므로 이 검사는 별도 저장소로 실행했다.
