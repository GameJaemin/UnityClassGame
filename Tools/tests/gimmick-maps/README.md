# 기믹 맵 에디터 검증

EXE/ZIP 빌드는 실행하지 않는다. 별도 복사 프로젝트의 실제 Main 씬에서 Unity 6000.6.3f1 에디터 Play 모드를 사용한다.

`GimmickMapEntry.cs`는 복사본 Assets/Scripts/Editor, `GimmickMapRunner.cs`는 Assets/Scripts에 복사한다. 원본 Assets/Scripts·StreamingAssets/Maps 변경을 복사본에도 반영한다. 실행 인자는 `-batchmode -nographics -projectPath <복사본> -executeMethod GimmickMapEntry.Run -logFile <로그>`이며 종료는 러너가 담당하므로 `-quit`는 넣지 않는다. PlayerPrefs는 CodexTests/GimmickMaps로 격리한다.

2026-10-07 결과: 기믹 검사 90개 + 온라인 규칙 36개 + 5판 규칙 23개 통과. 온라인 규칙에는 보관 맵 포함 총 23개 파일의 4인 배치 검사가 들어 있다.

- 활성 맵 12개(기존 4·신규 8)의 출발 위치, 기믹 변경 시 해시 변경.
- 장치 생성·이전 맵 장치 제거·실제 얼음 이동/회전·룰렛 미리보기.
- 여러 이동 시각의 서로 다른 발판/정적 얼음 Collider 간 간섭 검사.
- 회전/이동 접촉점 운반 계산·실제 캐릭터 착지와 왕복 발판 위 2초 운반.
- 클라이언트 얼음 붕괴 차단·호스트의 60초 붕괴.
- 피스톤 예고 중 무타격·전진 시 실제 캐릭터 밀침.

회전 발판 크기/주변 간격과 물리 좌표 갱신을 수정해 발견된 간섭·승객 이동 오류를 해결했다. 큰 회전 맵의 중앙 얼음 누락도 수정했다. Unity 내부 Search 색인 예외는 별도 에디터 로그에 있었지만 게임 스크립트 검사는 완료됐다.

그래픽 없는 검사이므로 실제 렌더·포인터·플레이 감각은 별도 확인이 필요하다. 온라인 검사는 규칙 및 호스트/클라이언트 판정 분기 검사이며, 새 기믹으로 실제 두 Relay 참가자를 플레이하는 통신 검사는 이번 작업에서 실행하지 않았다. AI는 이동한 발판의 현재 위치를 탐색하며 미래의 접안 시점을 예측하지 않는다.
