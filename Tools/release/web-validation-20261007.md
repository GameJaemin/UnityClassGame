# 웹 배포 검증 (2026-10-07)

원본 프로젝트를 복사한 Unity 6000.6.3f1 프로젝트에서 Windows 설정을 유지하고 WebGL로 빌드했다.

## 자동 검사

- 온라인 규칙 42개, 5판 시리즈 규칙 23개 통과.
- JSON 29개 전체의 디스크/웹 묶음 맵 해시 일치. Load는 매번 새 MapData를 반환한다.
- 최종 빌드 결과와 경고 수: `build-result-20261007-web.txt`.
- gzip 리소스 무결성 및 ZIP CRC, ZIP 최상위 index.html, 글꼴 OFL 포함 확인.

## 실제 브라우저

로컬 HTTP 서버에서 Codex in-app Chromium 브라우저의 두 탭으로 실제 Authentication/Sessions/Relay를 이용했다. 같은 브라우저의 두 탭에서도 서로 다른 게스트로 연결된다.

- 한글 UI 정상 표시, 시작하기 및 캐릭터 오른쪽 버튼으로 사자→북극곰 선택.
- 닉네임/방 코드 입력, 호스트 방 생성과 클라이언트 참가, 2인 로비와 준비 완료 동기화.
- 준비 각 1회 뒤 5판 자동 진행. 라운드 중 클라이언트 연결 유지, 공통 얼음 개수와 경기 시간 표시.
- 최종 순위/점수 양쪽 일치: NPC 2 16점, NPC 1 14점, 호스트 13점, 클라이언트 7점.
- 호스트 결과 버튼으로 양쪽 로비 복귀, 두 참가자 유지. 클라이언트 나가기→타이틀로 버튼 정상 동작.
- 두 온라인 탭의 5판 진행 중 error 수준 브라우저 로그 없음.
- 최종 UI 수정은 라운드 표시를 얼음 HUD 아래로 이동하고, 경기 중 나가기 버튼을 시간/우승 HUD 아래로 이동한다. 결과 화면 나가기 버튼은 우측 상단·작은 크기·55% 투명도를 유지한다.
- 최종 산출물 새 탭 시작/솔로 3판 자동 이동/경기 나가기→타이틀 정상 확인. error 수준 로그 없음. `web-final-gameplay.jpg`에 라운드와 경기 나가기 버튼이 HUD에 겹치지 않는 화면을 저장했다.

증거: `docs/screenshots/web-five-rounds-host.jpg`, `web-five-rounds-client.jpg`.

이 검사는 같은 PC의 두 탭과 로컬 HTTP에서 수행했다. 실제 itch.io iframe·다른 PC·모바일·Windows/Web 혼합 참가를 검증한 결과로 해석하지 않는다. 페이지 새로고침 과정에서 일회성 NullReference 로그가 관찰되었으나 새 탭 실행과 입력은 정상이며, 페이지 종료 시의 로그인지 추가 재현 확인이 필요하다. 브라우저의 User-Agent 관리/다운로드 Content-Length 경고와 URP의 미지원 FSR 셰이더 경고가 있다.
