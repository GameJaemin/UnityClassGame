시련

플레이어와 AI 봇 모두에게 적용됩니다. 모든 시련은 예고 뒤에 일어나 피할 수 있고, 버틴 시간이 길어질수록 하나씩 늘어나며, 처음 나올 때 안내 문구가 뜹니다.

눈덩이 낙하15초~ · 맞으면 2초 기절, 떨어진 칸 1단계 깨짐, 시간이 지날수록 개수 증가
예고: 그림자가 1.5초 동안 커지고 눈덩이가 내려옴
찬바람30초~ · 3초 동안 한 방향으로 모두를 밀어냄
예고: "찬바람! →" 안내 + 눈보라 줄기
고드름45초~ · 떨어진 칸 즉시 깨짐 + 1초 기절
예고: 붉은 원이 1.3초 동안 깜빡이며 커짐
펭귄 슬라이딩60초~ · 한 줄을 미끄러져 지나감 (깨진 칸 위도), 부딪히면 크게 밀려남
예고: 줄 끝에서 1초 뒤뚱 + 지나갈 줄이 붉게 표시
0 ~ 15초시련 없음 (조작 익히기)
15초 ~눈덩이 낙하 (4~6초마다)
30초 ~+ 찬바람 (12~16초마다)
45초 ~+ 고드름 (6~9초마다)
60초 ~+ 펭귄 슬라이딩 (7~10초마다)

버틴 시간 기준이며 수치는 플레이 테스트로 조정합니다. 방패는 맞는 것만 막고 고드름이 블럭을 깨는 것은 못 막습니다. 기절한 동안에는 오래 서 있기 타이머를 멈춥니다.

할 일 목록

미정 사항

  • 시련 시작 시간 (눈덩이 15초 / 찬바람 30초 / 고드름 45초 / 펭귄 60초, 플레이 테스트로 조정)
  • 얼음 깨짐 수치 (기본값: 3번 밟으면 흔들림, 흔들림 1초 뒤 깨짐, 오래 서 있기 2초)
  • 얼음 미끄러짐 적용 여부 (Thin Ice는 미끄러움, 선택)
  • 게임 시작 시 처음부터 빈칸을 둘지 여부
  • 펭귄 슬라이딩: 깨진 블럭(빈칸)을 지날 때 → 우선 추천안(그대로 미끄러져 지나감)으로 구현함
